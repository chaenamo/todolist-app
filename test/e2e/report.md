## 3. 발견 사항

| ID | 심각도 | 내용 | 재현 | 관련 |

| O-1 | 관찰 | 재방문 시 refresh를 먼저 하지 않고 401을 받은 뒤 갱신한다. 그래서 첫 요청 2건(`GET /api/categories`, `GET /api/todos`)이 401로 낭비된다. 동작은 정상. 문서(SC-02-A1)는 "refresh로 access token을 먼저 발급" | 새로고침 후 네트워크 탭 | SC-02-A1 |

## 4. 범위·한계

- 14일 refresh 만료와 15분 access 만료는 시간을 기다리지 않았다. 무효 토큰과 메모리 토큰이 없는 상태로 같은 경로를 확인했다.
- SC-05-A4(자정 경과)는 확인하지 않았다.
- 접근성(NFR-17)은 범위 밖이다.
- 테스트 데이터는 dev DB에 남겨 두었다(위 3개 계정).
